# Proposed text-only style dropdown

Design demo requested before another APK. The proposed floating menu is 144 dp wide with seven compact 28 dp text rows and 8 dp padding. It opens beside the pencil icon, uses a selected-style checkmark, and would apply and dismiss on a row tap. There are no image previews, thumbnails, header, Apply/Cancel buttons or separate picker bar.

- [Portrait UI](screenshots/proposed-text-dropdown-portrait.png)
- [Landscape UI](screenshots/proposed-text-dropdown-landscape.png)
- [Menu close-up](screenshots/proposed-text-dropdown-closeup.png)

These are proposed layouts rendered with the existing native player and sample artwork; the menu is a design overlay. No production code or APK was changed. The existing v1.18 APK still has the previous selector.
